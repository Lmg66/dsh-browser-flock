# Browser Flock v0.1.2 — 浏览器图标与 Harness rc.5 适配

## 中文

本版本合并 Harness 新版适配与浏览器图标修复，替代 v0.1.0 作为最新版本。

- **适配 DeepSeek Harness `0.2.1-rc.5`**：更新精确运行时要求、三个直接 DSH 依赖及依赖锁文件，解决旧版限定 rc.3 而无法加载的问题。
- **恢复 Chrome、Edge、Firefox、Brave 品牌图标**：替换公开分发版中的字母图标，构建时将图片以 data URI 内嵌到客户端，分发后无需联网下载或读取开发机图片。
- 保留 `@local/dsh-browser-flock` 插件身份、现有数据路径与格式，无需迁移浏览器 profile 或录制。
- 同步更新中英文安装、兼容范围和第三方图形说明。v0.1.1 的兼容工作一并包含在此版本中，未单独公开发布。

### 安装 / 升级

需要 Windows、Harness `0.2.1-rc.5` 和自行安装的浏览器。下载 `local-dsh-browser-flock-0.1.2.tgz`，通过 Harness 的 `plugin_manager install_bundle` 安装并检查 `application`、`warnings`、`nextStep`。

若返回 `already-installed`，先用 `remove_bundle` 移除 `@local/dsh-browser-flock` 安装登记，再安装新包；保留现有 `data/browser-flock` 数据目录。升级前停止进行中的录制，应用成功后刷新页面。若 Windows 返回 EPERM 或依赖错误，应修复安装错误后再继续，不能视为已安装成功。v0.1.0 仍保留供 Harness rc.3 使用。

附件包括安装包、完整源码 ZIP 和 SHA-256 校验值。源码 ZIP 包含构建脚本、测试与锁文件，不含依赖、个人浏览器数据或录制。

### 验证范围

- 构建、manifest/JavaScript 检查及 **141/141 自动化测试通过**。
- 核对四种内嵌图标解码后的内容与源文件逐字节一致，安装包收录全部图片。
- rc.5 适配阶段验证过安装、Client 插槽注册、AI 查询工具与原有数据读取；图标修复后本机依赖恢复、重新启用返回 `applied`。原有 15 个 profile、12 个录制目录保留。
- 图标修复后的页面视觉效果尚未重新核验；完整浏览器生命周期、代理、录制和扩展实机矩阵没有在本次更新重跑。历史覆盖与已知限制见 [测试说明](https://github.com/Lmg66/dsh-browser-flock/blob/v0.1.2/docs/TESTING.md)，包括 Brave 普通关闭可能超时。

## English

This release combines the Harness compatibility update and browser-icon fix.

- Target **DeepSeek Harness `0.2.1-rc.5`**, updating the exact engine requirement, three direct DSH dependencies and lockfile.
- Restore Chrome, Edge, Firefox and Brave brand artwork in place of letter icons. Images are embedded as data URIs at build time, without runtime network requests or development-machine file paths.
- Preserve package identity, browser data paths and data format. No profile or recording migration is required.
- Include the previously local v0.1.1 compatibility work and update bilingual documentation and third-party notices.

Requires Windows, Harness rc.5 and a separately installed browser. Install the `.tgz` through plugin management and check its result. If installation returns `already-installed`, remove the existing bundle registration first, preserving `data/browser-flock`, then install the new package. Stop active recordings before upgrading and refresh after successful application. Windows EPERM or dependency errors must be resolved before treating installation as successful. Version 0.1.0 remains available for Harness rc.3.

Assets include the installation tarball, full source ZIP and SHA-256 checksums. Build, syntax/manifest checks and **141/141 tests passed**. Embedded image bytes match all four source assets. Earlier rc.5 live checks covered installation, Client registration, AI tools and saved-data reads. Following the icon fix, local dependency recovery and re-enabling returned `applied`, with existing data directories preserved. Visual display after the icon fix and the complete real-browser integration matrix were not rerun. See the [testing notes](https://github.com/Lmg66/dsh-browser-flock/blob/v0.1.2/docs/TESTING.md) for historical coverage and limitations.
