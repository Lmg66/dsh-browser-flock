# Browser Flock v0.1.1 — Harness rc.5 compatibility

## 中文

本版本适配 **DeepSeek Harness `0.2.1-rc.5`**，解决旧版本因精确限定 rc.3 而被阻止加载的问题。

- 将 DSH 运行时要求和三个直接依赖更新为 `0.2.1-rc.5`，重新生成依赖锁文件。
- 核对新版工具执行、权限审批、sandboxPolicy、Typert RPC 与 Client 插槽契约；现有 Host/Client 实现继续兼容。
- 保持插件身份、数据目录与数据格式，升级无需迁移浏览器 profile 或录制。
- 更新双语兼容与安装说明。

### 验证

构建、语法检查与 **141/141 自动化测试通过**。本机安装返回 `application: applied`，没有警告；Client 侧栏与主面板注册为 active。AI 查询工具可读取已有实例、浏览器、代理预设、扩展库和录制。升级前后的 profile/录制目录数量一致，数据所有权文件校验值一致。

本次未重跑完整浏览器启动、关闭、代理、录制和扩展实机矩阵，也未重新进行视觉布局检查。此前 rc.3 的实机覆盖和已知限制见 [测试说明](../TESTING.md)，包括 Brave 普通关闭可能超时。

### 安装

需要 Windows、Harness `0.2.1-rc.5` 和自行安装的浏览器。安装包为 `local-dsh-browser-flock-0.1.1.tgz`。使用 Harness 的 `plugin_manager install_bundle` 安装并检查返回结果；若返回 `already-installed`，先移除 `@local/dsh-browser-flock` 安装登记，再安装新包。保留现有数据目录，升级前停止正在进行的录制。旧的 v0.1.0 安装包适用于 Harness rc.3。

此文件是发布文案；是否已经公开发布，以 GitHub Releases 页面为准。

## English

This version targets **DeepSeek Harness `0.2.1-rc.5`**, fixing the compatibility block caused by the previous exact rc.3 requirement.

- Update the DSH engine requirement and all three direct dependencies to rc.5; regenerate the lockfile.
- Verify current tool execution, approval, sandboxPolicy, Typert RPC and Client slot contracts. The existing Host/Client implementation remains compatible.
- Preserve package identity, data paths and data format. Existing browser profiles and recordings need no migration.
- Update bilingual compatibility and installation documentation.

Build, syntax checks and **141/141 automated tests passed**. Live installation returned `application: applied` without warnings. The Client sidebar and main panel registered as active. AI query tools read existing instances, browser installations, proxy presets, extensions and recordings. Browser-profile and recording directory counts and the ownership ledger hash were unchanged.

The complete browser lifecycle/proxy/recording/extension integration matrix and visual layout checks were not rerun for this dependency update. Historical rc.3 coverage and limitations, including Brave normal-close timeouts, remain in the [testing notes](../TESTING.md).

Requires Windows, Harness rc.5 and a separately installed browser. Install `local-dsh-browser-flock-0.1.1.tgz` through plugin management. If it returns `already-installed`, remove the existing bundle registration before installing the new package, preserving the data directory. Stop active recordings before upgrading. Version 0.1.0 remains the rc.3 package.
