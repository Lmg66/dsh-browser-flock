## 中文

Browser Flock（浏览器群）是 DeepSeek Harness 的本机浏览器管理插件，为多个账号创建独立的浏览器环境，并让 AI 通过工具管理这些实例。

这是 **v0.1.0 首次正式发布**。主要适配 Windows + Chrome，欢迎使用 AI 继续开发与适配其他环境。

### 主要功能

- 自动识别本机 Chrome、Edge、Brave、Firefox。
- AI 连续调用工具，批量创建、重开和关闭独立浏览器实例。
- 为新实例分别配置系统代理、直连、HTTP 或 SOCKS5 代理。
- 收录扩展代码并在多个 Chromium 实例加载，各实例的账号和扩展数据独立保存。
- 通过本机 CDP 连接控制 Chromium 页面。
- 录制点击、输入、导航和 HTTP 请求/响应；同一 Harness profile 的其他 AI 对话可读取保存记录。
- 中英文界面与项目文档，MIT 许可，允许二次开发和商业使用。

### 环境与安装

需要 **Windows、DeepSeek Harness `0.2.1-rc.3`** 和自行安装的浏览器。开发与独立脚本要求 Node.js 22+。

下载附件 `local-dsh-browser-flock-0.1.0.tgz`，然后在 Harness 对话中发送，替换为实际路径：

```text
请用 plugin_manager 的 install_bundle 安装
C:\Downloads\local-dsh-browser-flock-0.1.0.tgz
并检查 application、warnings 和 nextStep。
```

应用成功后刷新页面。`source.zip` 用于查看和修改源码；插件安装应选择 `.tgz`。`SHA256SUMS.txt` 提供附件校验值。

## English

Browser Flock is a local-browser management plugin for DeepSeek Harness. It creates separate browser profiles for multiple accounts and exposes tools for AI to manage them.

This is the **v0.1.0 initial release**, primarily developed for Windows + Chrome. AI-assisted contributions and further platform adaptations are welcome.

### Features

- Discover locally installed Chrome, Edge, Brave and Firefox.
- Let AI coordinate multiple tool calls to create, reopen and close isolated browser instances.
- Assign system, direct, HTTP or SOCKS5 proxy settings to new instances.
- Capture extension code and load it into multiple Chromium instances with independent account and extension storage.
- Connect to Chromium pages through local CDP endpoints.
- Record clicks, input, navigation and HTTP requests/responses; other AI conversations in the same Harness profile can read saved recordings.
- English/Chinese UI and documentation, with an MIT license permitting derivative work and commercial use.

### Requirements and installation

Requires **Windows, DeepSeek Harness `0.2.1-rc.3`** and a separately installed browser. Development and standalone scripts require Node.js 22+.

Download `local-dsh-browser-flock-0.1.0.tgz` and ask Harness, using the actual local path:

```text
Use plugin_manager install_bundle to install
C:\Downloads\local-dsh-browser-flock-0.1.0.tgz
and check application, warnings and nextStep.
```

Refresh the page after successful application. Use `.tgz` for installation and `source.zip` for development. Attachment hashes are provided in `SHA256SUMS.txt`.

### Release preparation

Includes bilingual documentation, MIT licensing, third-party notices, release guidance and three real management-page screenshots. The distribution uses original letter icons and includes an installable tarball, source ZIP and SHA-256 checksums.

### Validation and limitations

- v0.1.0 passed its build, syntax checks and **141/141 automated tests** (0 failed, 0 skipped). The user confirmed that the GUI works; the README shows instances, local browsers and recording details.
- HTTP proxy checks passed for all four browsers. CDP, recording, extension isolation and reopen assertions passed for Chrome, Edge and Brave.
- **Brave normal close may time out.** There is no automatic force escalation; explicit force close can lose unsaved work.
- Firefox supports basic lifecycle and proxy operations only, without this plugin's CDP, recordings or extension library. macOS/Linux are currently unsupported.
- SOCKS5, external HTTPS CONNECT, long recordings and taskbar appearance have not received complete live verification.

**Recordings preserve raw passwords, cookies, Authorization headers and request/response bodies.** Review sensitive content before sharing and keep real recordings out of public repositories. Automated replay is not provided.
